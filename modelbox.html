Modelo em caixa, Model Box HTML

Os elementos html são estruturados em um modelo denomindao modelbox, que refere-se a caracteristica de um elemento e pode conter outros elementos, sendo que cada um possui uma estrutura interna, similar a ideia de uma caixa dentro da outra.

Estrutura de um elemento HTML

Todos elementos HTML possuem conteúdo, padding, borda, offset. Sendo a região de conteúdo estruturada em três camadas 1) background-color 2) background-image 3) Content
