Sobre git

Sobre git discutimos o funcionamento do git, o que é o workcopy, stage, repositório. Os comandos git utilizaos são listados abaixo:

  • git init | cria um repositório git vazio .git
  • git status | exibe estado do rep.
  • git add | adiciona no stage
  • git commit -m "msg" | faz um commit
  • git log |lista os commits da branch(ramo)atual
  • git checkout branch | recuperawk a partir de um branch
  • git diff
  • git config user.name "joanagc-sudo"
  • git config user.email "joanagc.goncalves@gmail.com"
  • git log --onelin
  • git remote add origin url
  • git push origin main
  • git clone https://rbeninca.github.io/notas/notas/oficina-git/
